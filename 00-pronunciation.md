# Pronuntiatio — How to Pronounce Church Latin

Church (Ecclesiastical) Latin is pronounced much like Italian. Capitals in the guide mark the stressed syllable.

|     | Latina    | Pronunciation    | English                                                     |
| --- | --------- | ---------------- | ----------------------------------------------------------- |
|     | Deus      | DEH-oos          | Every vowel is sounded: a = "ah", e = "eh", i = "ee", o = "oh", u = "oo". (God) |
|     | caeli     | CHEH-lee         | ae and oe both sound like "e" in "bet". (of heaven)         |
|     | pacem     | PAH-chehm        | c before e, i, ae, oe = "ch" as in "church". (peace)        |
|     | Credo     | KREH-doh         | c before a, o, u or a consonant = "k". (I believe)          |
|     | Christe   | KREE-steh        | ch = "k". (O Christ)                                        |
|     | unigenite | oo-nee-JEH-nee-teh | g before e, i = "j" as in "jet". (only-begotten)          |
|     | Agnus     | AH-nyoos         | gn = "ny" as in "canyon". (Lamb)                            |
|     | gratias   | GRAH-tsee-ahs    | ti before a vowel = "tsee". (thanks)                        |
|     | descendit | deh-SHEHN-deet   | sc before e, i = "sh". (came down)                          |
|     | excelsis  | ek-SHEL-sees     | xc before e, i = "ksh". (in the highest)                    |
|     | qui       | kwee             | qu = "kw". (who)                                            |
|     | hominibus | oh-MEE-nee-boos  | h is silent. (to people)                                    |
|     | Iesu      | YEH-soo          | i before a vowel at the start of a word = "y". (Jesus)      |
|     | Laudamus  | lau-DAH-moos     | au = "ow" as in "cow". (we praise)                          |
|     | terra     | TEHR-rah         | Double consonants are held a little longer. (earth)         |
